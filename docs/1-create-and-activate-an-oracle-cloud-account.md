# Crear y activar una cuenta de Oracle Cloud

Si ya tienes una tenancy de Oracle Cloud Infrastructure (OCI) autorizada para el laboratorio, continúa con la preparación de servicios. Para crear una, sigue el registro y la activación en Oracle. [Registro de Oracle Cloud](https://www.oracle.com/cloud/free/) · [Preparar servicios y permisos](2-creating-and-preparing-services-for-the-project.md)

Después de activar la cuenta, comprueba que puedes entrar a la consola de OCI y que tienes acceso a la región del laboratorio. El administrador de la tenancy prepara el compartimento y los permisos de la identidad que usarás. Antes de desplegar, revisa la cuota de los servicios y el coste estimado de los recursos.
